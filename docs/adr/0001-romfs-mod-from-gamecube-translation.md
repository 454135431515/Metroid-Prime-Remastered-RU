# ADR 0001: RomFS-мод для PrimeRecomp из перевода GameCube

## Статус
Принято

## Дата
2026-11-07

## Контекст
PrimeRecomp (gminustwo/primerecomp) — статическая рекомпиляция Metroid Prime Remastered
(Switch, v1.0.0) под ПК и Android; игра берётся из NSP/XCI игрока. Моды — в формате RomFS, как
у Ryujinx/yuzu: файл с путём RomFS подменяет файл игры. Текст Remastered — 30 ресурсов MSBT в 5
архивах `.pak`, шрифты — 3 FONT с атласами TXTR (R1). Русского языка в игре нет. Готовый
фанатский перевод (mastertranslate) владелец не берёт: перевод GameCube точнее.

## Решение
- Русский пишется в языковые блоки английского (USEN, EUEN) ресурсов MSBT; остальные языки
  остаются. Кириллица дописывается в шрифты (ADR 0002).
- Единственный источник перевода — `MP russian/text/ru.json` (перевод GameCube): сборка читает
  его на месте, не копирует. Здесь — только строки, которых на GameCube нет, и правила переноса
  (ADR 0003).
- Результат — RomFS-мод с пересобранными `.pak`. Он собирается у игрока из его NSP и ключей:
  изменённые архивы — данные Nintendo, их не раздаём (как вариант A первой части).

## Рассмотренные альтернативы
- Свои файлы вместо архивов: PrimeRecomp подменяет только файлы RomFS целиком, ресурс внутри
  `.pak` по отдельности не подменить.
- Перевод mastertranslate: отклонён владельцем.

## Последствия
- Нужны чтение и запись `.pak` (R4), MSBT, FONT, TXTR.
- Правка в `ru.json` попадает в обе версии; формат ключей GameCube менять нельзя без этой сборки.

# ADR 0002: кириллица в шрифтах Remastered — генератор HD-шрифта GameCube

## Статус
Принято

## Дата
2026-11-07

## Контекст
Шрифты Remastered: FONT (записи глифов — те же 9 чисел, что `deface.sdfont` порта Odrannnn) и
атлас TXTR (R8, поле расстояний, block linear Tegra, LZSS 3). Перевод GameCube уже строит
кириллицу на этом же атласе (TR2, `MP russian/tools/hd_font.py`, рецепты `cyrillic.py`,
проверено в игре; М/м — T4g).

## Решение
- Кириллица генерируется тем же `hd_font.build` из атласа и записей начертания 0 каждого шрифта;
  новые записи дописываются в конец FONT, v старых пересчитываются, атлас дорастает полками снизу.
- Атлас пишется обратно в формате игры: block linear и LZSS режима 3 (как в исходных данных).
- Шрифт MiscData (другая гарнитура, рисует только цифры и строку версии) не меняем.

## Рассмотренные альтернативы
- Несжатые данные атласа (режим 0): проще, но не проверено, что игра их принимает.
- Отдельный атлас для кириллицы: больше правок в FONT (списки текстур, размеры, отступы).

## Последствия
- Изменения рецептов букв в `MP russian` меняют и Remastered — проверять обе версии.

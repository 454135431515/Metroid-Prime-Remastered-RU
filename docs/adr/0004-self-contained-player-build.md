# ADR 0004: сборка у игрока из одного репозитория

## Статус
Принято

## Дата
2026-11-07

## Контекст
Сборка брала из соседней папки перевода GameCube (`MP russian`) код шрифтов (`cyrillic.py`,
`hd_font.py`, `font.py`) и тексты `text/ru.json` + `text/en.json`. `en.json` — английский текст,
извлечённый из образа GameCube: данные Nintendo, в репозитории его нет. Игроку пришлось бы
держать ещё и диск GameCube с собранным переводом GameCube — ради мода Remastered.

## Решение
- В репозитории лежат готовые копии:
  - `tools/gc/` — код шрифтов из metroid-prime-ru, байт в байт;
  - `text/ru-labels.json` — итог `tools/transfer.py`: {метка MSBT: русская строка}. Только
    строки, отличные от английских: перевод и коды разметки, без английского текста.
- Источник остаётся один: перевод и код шрифтов правятся в metroid-prime-ru, копии обновляет
  `tools/sync_gc.py`; `tools/test.sh` (`sync_gc.py --check`) падает, если копия отстала.
- `tools/build.py` берёт строки только из `text/ru-labels.json`. Перед записью сверяет, что каждая
  метка таблицы нашлась в архивах игры: иначе другая версия игры, мод не пишется.
- `install.py` в корне: NSP + `prod.keys` → извлечение 8 архивов со строками и шрифтами во
  временную папку → сборка → `<mods PrimeRecomp>/russian`.

## Последствия
- Игроку нужны только этот репозиторий, Python с пакетами из `requirements.txt`, свой NSP и ключи.
- Перенос (`tools/transfer.py`) и его отчёт — инструменты разработки: им по-прежнему нужны соседняя
  папка `MP russian` с `en.json` и `work/romfs`.
- Правка перевода GameCube попадает в Remastered только после `sync_gc.py` и коммита здесь.

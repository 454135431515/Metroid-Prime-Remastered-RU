# ADR 0003: перенос строк GameCube → Remastered и ручной перевод

## Статус
Принято

## Дата
2026-11-07

## Контекст
Метки строк Remastered `[STRG]_N` совпадают с ключами `ru.json`, но часть таблиц перенумерована,
часть строк переписана, есть новые строки (меню, бонусы, титры). Разметка разная: теги GameCube
`&…;` против кодов MSBT 0x0E/0x0F. Перевод GameCube местами перенесён под узкие поля GameCube.

## Решение
- Поиск: по метке, затем по английскому тексту без разметки (однозначное совпадение).
- Переносы: перенос слова склеивается, настоящий дефис остаётся — решает словарь слов перевода;
  нет переносов в Remastered — одиночные переносы становятся пробелами.
- Разметка: видимые теги GameCube (цвет, `&pop;` после цвета, значок) заменяются кодами
  Remastered по порядку; иначе русские куски встают между кодами. Не сошлось — ручной перевод.
- Ручной перевод: `text/ru-remastered.json` {метка: строка}, `‹n›` — n-й код английской строки
  Remastered; сборка проверяет, что использован каждый код ровно по номерам 1..n.
- Строка, переписанная в Remastered, переводится заново (подсказка — ближайший перевод GameCube):
  перенос старого перевода по похожести запрещён — меняется смысл («5 зарядов» → «10»).

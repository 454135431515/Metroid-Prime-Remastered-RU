# R1: разведка форматов Remastered

Ветка: `main` (первый коммит) · Статус: done · Размер: S

## Цель
Понять, где в Metroid Prime Remastered v1.0.0 лежат текст и шрифты и как их читать.

## Найдено
- RomFS: 341 файл, 6,9 ГБ; почти всё — архивы `.pak` (RFRM «PACK», каталог ресурсов ADIR: тип,
  GUID, версии, смещение, размеры распакованный/сжатый). `tools/nsp_romfs.py` достаёт файлы прямо
  из NSP (AES-XTS заголовок NCA, AES-CTR раздел, IVFC, RomFS), `tools/pak.py` читает каталог.
- Текст: 30 ресурсов `MSBT` в 5 архивах (`GuiSysMP1.pak` — 25). MSBT не сжаты. Ресурс — RFRM с 13
  блоками языков (USEN, EUEN, EUFR, USFR, EUSP, EUGE, EUIT, EUDU, JPJP, KOKO, CHTC, CHSC, USSP),
  в каждом MsgStdBn Nintendo (LBL1, ATR1, TXT2, UTF-16) — `tools/msbt.py`.
- Метки строк `[XXXXXXXX]_NNN` = ключи нашего перевода (таблица STRG GameCube, индекс).
  Уникальных строк 3132: 1854 есть в `MP russian/text/ru.json`; 709 именованных (меню, настройки,
  титры Remastered, ~5600 слов) — переводить; 569 с ключом, но без перевода (180 пустых, 25 новых
  индексов, остальные — таблицы, которых нет на диске GameCube).
- Управляющие коды текста — 0x0E (цвет, значки кнопок, параметры `{0}`), не теги `&…;` GameCube:
  при переносе текст меняется, коды сохраняются.
- Шрифты: 3 ресурса `FONT` (MiscData, GuiSysMP1, PreloadFrontEndMPT), сжаты.

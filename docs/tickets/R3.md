# R3: перенос перевода GameCube в строки Remastered

Ветка: `main` · Статус: in progress · Размер: M
Зависит от: R1

## Цель
Каждая строка USEN Remastered получает русский текст: из перевода GameCube, где он подходит,
иначе — ручной перевод.

## Решение
`tools/transfer.py` (разбиение на коды/текст — `tools/rtext.py`):
- метка `[STRG]_N` → `MP russian/text/ru.json`; не нашлась — тот же английский без разметки на
  GameCube (Remastered перенумеровал часть таблиц);
- переносы перевода под ширину GameCube: перенос слова склеивается, настоящий дефис остаётся (словарь
  слов перевода); если в Remastered переносов нет — одиночные переносы становятся пробелами;
- коды Remastered: видимые теги GameCube (цвет, &pop; после цвета, значок) заменяются кодами
  Remastered по порядку — русский порядок слов сохраняется («из ‹кордита›»); иначе русские куски
  текста встают между кодами Remastered;
- ручной перевод — `text/ru-remastered.json` {метка: строка}, коды — `‹n›` (n-й код английской
  строки Remastered), проверка: каждый код использован.

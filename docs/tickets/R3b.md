# R3b: перевод главного меню и настроек Remastered

Ветка: `r3b-menus` · Статус: review · Размер: M
Зависит от: R3, R2

## Цель
Главное меню Remastered (архив `PreloadFrontEndMPT.pak`, таблица d7233808) — по-русски целиком,
и всё это рисуется шрифтом меню.

## Сделано
- `text/ru-remastered.json`: 135 строк меню (выбор слота, сложность, настройки управления, звука,
  экрана, цветовой помощи, рассказчика и субтитров, бонусы: галереи, треки, персонажи) и 7
  полных названий миров (строка 3 таблиц миров — на GameCube её не было).
- Термины — из перевода GameCube и глоссария: «Плотность» (Opacity), «Инерция HUD», «Система
  подсказок», «Робот-улей», «Королева паразитов» (полное имя: в галерее место есть),
  «Робот-поджигатель» (без переноса GameCube).
- `FE_ENFORCED_CHARS` (набор символов, который меню держит загруженным) — дополнен кириллицей.
- Шрифт меню — урезанный игровой (те же глифы того же размера) без «», —, °, … и ещё 60 знаков:
  `tools/font.py --donor` переносит недостающие глифы из игрового шрифта, затем кириллица.
- Без длинного тире в строках меню не обойтись было бы только до переноса глифов; после него
  проверка символов чистая.

## Критерии приёмки
- [x] все 220 строк архива меню переведены (135 вручную, остальное — перенос GameCube)
- [x] все символы русских строк меню есть в шрифте меню (проверка по FONT, прочитанному обратно)
- [x] превью шрифта меню: «Вариа», тире, градус, многоточие, кириллица
- [ ] вычитка владельца (20–30 строк на пробу)
- [ ] в игре (R5)

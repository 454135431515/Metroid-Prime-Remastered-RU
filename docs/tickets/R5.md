# R5: RomFS-мод, сборщик у игрока, проверка в PrimeRecomp

Ветка: `r5-installer` · Статус: done · Размер: M
Зависит от: R4

## Цель
Игрок с PrimeRecomp ставит перевод из своей копии игры одной командой; репозиторий готов к
публикации: README с установкой и скриншотами, лицензии.

## Решение
- ADR 0004: копии кода шрифтов (`tools/gc/`) и таблица строк (`text/ru-labels.json`), синхронизация
  `tools/sync_gc.py`, сверка в `tools/test.sh`;
- `install.py <nsp> [--keys] [--mods]`: ключи рядом с NSP или `~/.switch/prod.keys`, папка модов
  по ОС из исходников PrimeRecomp v0.0.8 (`runtime/paths.c`; на Windows — рядом с exe, указывается);
- `tools/build.py`: строки из таблицы, проверка версии игры до записи мода;
- скриншоты PrimeRecomp v0.0.8 (тестовый режим `LARECOMP_INPUT`/`LARECOMP_SHOT_AT` на копии
  данных и сейвов), `LICENSE` (MIT), `text/LICENSE` (CC BY 4.0).
